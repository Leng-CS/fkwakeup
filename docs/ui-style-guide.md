# 云朵课表视觉规范

对应 Issue：[#34](https://github.com/Leng-CS/fkwakeup/issues/34)

## 1. 设计目标

课表每天都会被快速扫视，界面首先要让人一眼找到今天、当前节次和课程信息。
视觉风格以“轻松、柔和、偏卡通”为方向，但不牺牲周视图的信息密度。

参考 [Material 3 Expressive](https://m3.material.io/) 对色彩、形状与字体层级的组合方式，
以及 [Tiimo](https://www.tiimoapp.com/) 和 [Structured](https://structured.app/)
将日程组织成清晰视觉时间线的做法。只借鉴设计原则，不复制品牌视觉或界面结构。

## 2. 色彩

- **底色**：暖奶油白，降低纯白大面积带来的冷硬感。
- **主色**：蓝莓紫，用于主操作、选中态与页头。
- **辅助色**：蜜桃粉用于温和提示；薄荷绿用于日期和进度状态。
- **课程色**：继续使用课程色板或用户自定义色，主题不得覆盖课程辨识色。
- **深色模式**：保持相同色相关系，使用暖黑底色和提高明度后的主辅色。

正文、按钮和重要标签遵循 `4.5:1` 的最低对比度目标；装饰线与次要文字可以降低强调，
但不能依靠低对比度来表达唯一信息。

## 3. 形状与间距

- 小控件圆角 `8–12dp`，普通卡片 `18dp`，页面主卡片 `24–32dp`。
- 周视图课程块宽度有限，固定使用 `10dp` 圆角，避免圆角吞掉正文空间。
- 页面内容左右留白默认 `16dp`；紧凑网格内保持 `1–4dp` 的辨识间隔。
- 课程块增加浅色描边，形成贴纸感并隔开相邻颜色。

## 4. 字体层级

- 页面标题使用粗体，信息卡标题使用半粗体，正文保持常规字重。
- 周视图课程名保持粗体；时间和地点降低一级强调，但不降低字号到不可读。
- 不引入额外字体依赖，优先使用系统无衬线字体，保证中文覆盖与安装包体积。

## 5. 页面规则

### 周视图

- 学期和周次放入柔和的主色容器，周切换使用圆形按钮。
- “导入 / 管理”共用浅色胶囊按钮并与周切换分层，避免小屏横向挤压。
- 今天使用薄荷色胶囊和淡色列背景；当前节次使用蜜桃色强调。
- 课程块继续显示时间、课程名、地点，既有编辑、灰化和当前课程边框逻辑不变。

### 课程管理

- 顶栏只负责返回和标题；导出、学期、节次、小组件集中在两行工具区。
- 当前学期和课程数量使用主信息卡展示。
- 课程列表用颜色圆点承接课程色，新增课程保留为页面主按钮。

### 导入流程

- 操作步骤、AI 操作区和文件导入区分别使用蓝紫、蜜桃、薄荷容器。
- 输入和错误信息沿用 Material 组件与语义色，避免为了卡通感削弱错误识别。

## 6. 边界

- 本次改造不修改第 4、5 章的数据契约，不改变导航路径和业务动作。
- 小组件拥有独立背景配置，不强制同步 App 的页面背景。
- 动效和自定义插画留待后续独立需求；当前版本不增加第三方依赖和系统权限。
