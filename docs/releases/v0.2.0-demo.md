本版本汇集 M9 的三项主要改进：

- 桌面小组件统一为一个入口，支持 `4×1 / 4×2 / 4×4`、内部纵向课程列表、按实例配置、课程范围选择，以及纯色、渐变、预设图和相册图片背景。
- 节次时间表支持全局单节时长和课间时长、时间滚轮、上午/下午等断点递推，以及确认前的相邻节次冲突校验。
- 周视图、课程管理和导入流程采用轻松柔和的卡通视觉；周视图“导入 / 管理”按钮统一为胶囊样式。
- 小组件继续保留课程边界精确刷新能力。

Android Lint、全量单元测试与 Debug APK 构建均已通过；关键页面已在 Pixel 8 API 35 模拟器检查。

安装包为调试签名 APK，最低支持 Android 8.0（API 26）。对应的 SHA-256 校验文件与 APK 一并提供。
