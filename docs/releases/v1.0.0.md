# fkwakeup v1.0.0

fkwakeup 首个正式版本。把教务课表截图交给你常用的 AI，即可识别并导入课程；也可以手动创建和管理课表。

## 功能

- 周视图、课程管理、多学期和可配置的节次时间表。
- 识别线下课程、固定节次直播网课和异步网课，并在导入预览中补齐不完整信息。
- 4×1、4×2、4×4 桌面小组件，支持内部纵向浏览和按实例配置。
- 课程提醒、单次课程提醒例外，以及保存前的课程时间冲突提示。
- 本地数据、课表导出与重新导入。
- 轻松、柔和的卡通视觉设计。

## 验证

全量单元测试、Android Lint 和 Debug APK 构建通过。Debug APK 已在 Android 35 模拟器安装并启动。

安装包为调试签名 APK，最低支持 Android 8.0（API 26）。
